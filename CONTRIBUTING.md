# Contributing

Thanks for considering a contribution!

1. Fork the repository and create a focused feature branch.
2. Use a supported Python version (3.10+).
3. Install dependencies with `pip install -r requirements.txt`.
4. Add or update tests for behavior changes.
5. Run `python -m pytest -q` before opening a pull request.
6. Describe the motivation, implementation, and any security or privacy impact.

Please never commit secrets, `.env` files, local databases, or personal data.
